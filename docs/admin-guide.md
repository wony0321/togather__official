# 어드민 가이드

## 접속 방법

1. `/admin/login` 접속
2. 관리자 이메일 + 비밀번호 입력
3. 로그인 후 자동으로 `/admin` 대시보드 이동

로그인 상태는 브라우저 localStorage에 저장되므로 새로고침 후에도 유지됩니다.

## 문의 관리

1. 좌측 사이드바 **문의 관리** 클릭
2. 목록에서 상태 필터 적용 (전체/대기/진행중/완료/취소)
3. 행 클릭 시 우측에 상세 정보 패널 표시
4. 상태 드롭다운으로 진행 상태 변경

### 문의 상태 설명

| 상태 | 의미 |
|------|------|
| 대기 | 접수됨, 미확인 |
| 진행중 | 담당자 배정 및 연락 진행 중 |
| 완료 | 계약 완료 또는 상담 종료 |
| 취소 | 고객 취소 또는 미진행 |

## 고객사 관리

- **문의 관리**에서 상태를 "완료"로 변경한 후, 백엔드에서 고객사로 전환 처리
- 고객사 목록에서 플랜, 활성 여부, 시작일 확인 가능

## 팀원 관리

1. **팀원 관리** 메뉴에서 현재 팀원 목록 확인
2. **+ 팀원 추가** 버튼으로 새 팀원 추가
3. 각 카드의 **편집** 버튼으로 정보 수정
4. **삭제** 버튼으로 제거 (확인 다이얼로그 표시)

> 백엔드 연동 전까지 팀원 변경 사항은 새로고침 시 초기화됩니다.
> 영구 반영을 위해서는 `src/data/team.js` 파일을 직접 수정하세요.

## 로그아웃

좌측 사이드바 하단의 **로그아웃** 버튼 클릭.
