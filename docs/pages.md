# 페이지 구성 문서

## 공개 페이지

### Home (`/`)
- **목적**: 서비스 랜딩, 전환(문의 신청) 유도
- **섹션**:
  1. Hero — 메인 가치 제안 + CTA 버튼
  2. Stats — 타깃 조직 수, 구축 기간 등 수치
  3. Problem & Solution — 기존 문제점 vs ToGather 해결책
  4. Features — 6개 핵심 기능 카드
  5. Target — 타깃 조직 유형 (교회, 학원, 비영리, 커뮤니티)
  6. CTA — 하단 전환 섹션

### Service (`/service`)
- **목적**: 제품 상세 설명, 경쟁사 대비 차별화 어필
- **섹션**:
  1. Hero
  2. 제품 구성 (운영자 Admin vs 사용자 Web/App)
  3. 서비스 이용 흐름 (4단계)
  4. 주요 기능
  5. 경쟁사 비교표 (치윰, 세움, 교회톡, CH2CH)
  6. CTA

### Pricing (`/pricing`)
- **목적**: 요금제 투명 공개, 문의 전환
- **섹션**:
  1. 헤더 (초기 개설비 명시)
  2. 3개 요금제 카드 (베이직 29,900 / 스탠다드 39,900 / 프리미엄 59,900)
  3. 맞춤형 요금제 (별도 상담)
  4. FAQ

### Team (`/team`)
- **목적**: 팀 신뢰도 형성
- **섹션**:
  1. 팀원 카드 그리드 (`src/data/team.js` 기반)
  2. 협력 파트너 (GOODTV, CBS)
  3. 미션 선언

### Contact (`/contact`)
- **목적**: 문의 접수
- **폼 필드**:
  - 조직명 (필수)
  - 조직 유형 (필수): 교회, 비영리, 학원, 커뮤니티, 기타
  - 담당자 이름 (필수)
  - 이메일 (필수)
  - 연락처
  - 구성원 수: 50명 이하 / 51~100 / 101~300 / 300명 이상
  - 관심 요금제: 베이직 / 스탠다드 / 프리미엄 / 맞춤형
  - 문의 내용
  - 개인정보 동의 (필수)

## 어드민 페이지

### Login (`/admin/login`)
- 별도 레이아웃 (Header/Footer/Sidebar 없음)
- 로그인 실패 시 에러 메시지 표시

### Dashboard (`/admin`)
- 4개 통계 카드 (전체 문의, 미처리, 활성 고객사, 이번 달 신규)
- 최근 문의 5건 목록 (→ 전체보기 링크)

### Inquiries (`/admin/inquiries`)
- 문의 목록 테이블 (상태 필터)
- 행 클릭 시 우측 디테일 패널
- 인라인 상태 변경 (대기/진행중/완료/취소)

### Clients (`/admin/clients`)
- 고객사 목록 테이블
- 이름·담당자 검색

### Team Manage (`/admin/team`)
- 팀원 카드 그리드
- 추가/편집/삭제 (모달 폼)
- 백엔드 연동 전: 로컬 state로 동작
